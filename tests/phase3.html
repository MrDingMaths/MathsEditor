Keyboard model

  • Tab in text — inserts a maths island at the caret and focuses it
  • Tab inside maths — MathLive handles it (cycles placeholders)
  • Esc inside maths — exits to text mode, caret after island; island removed if empty
  • ← / → at boundary — exits island; island removed if empty
  • Click outside a focused maths island — exits; island removed if empty
  • Backspace immediately after an island, or Delete immediately before — removes the island as a unit (browser default)
